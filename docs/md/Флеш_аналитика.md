# Флеш-аналитика: как это работает

Рабочая инструкция к кейсу 9 (см. `docs/Кейс9_Флеш_для_фондов.md` — продукт и экономика).
Здесь — команды, ритм, правила и ограничения. Протокол — `core/lanmil/flash.py` (зафиксирован
14.11.2026 до первых прогнозов).

## Ритм

- **Недельный обзор** — понедельник, `python core/flash.py --week` (топ-10 пар с вероятностями на 30/90 суток).
- **Внеочередной флеш** — при событии, режим скорости: черновик за минуты, фиксация после проверки текста.
- **Скоринг** — по сроку проверки: активы собираются автоматически, событие вносится вручную по UCDP Candidate.

## Режим скорости (2–4 часа на флеш)

```bash
python -I core/flash.py --week                                  # что горит на этой неделе
python -I core/flash.py --draft IND-PAK --class border_war      # черновик записки
python -I core/flash.py --fix IND-PAK --class border_war --event "…" --source "…"
python -I tools/flash/make_flash.py --all                       # страницы и трек-рекорд
```

Черновик пишется в `data/flash/drafts/<ПАРА>_<КЛАСС>_<дата>.md`; фиксация добавляет запись в
`data/flash/forecasts.json` (Ф-001…) и пустую строку в `observations.json`. Повторная фиксация той же
пары и класса запрещена без `--force` (протокол).

## Правила, которые нельзя нарушать

1. **Фиксация до исхода.** Запись создаётся до начала периода проверки; `resolves` = конец периода.
2. **Протокол не меняется после расчёта.** Менять `core/lanmil/flash.py` можно только до новой серии
   прогнозов и отдельным коммитом.
3. **Результат публикуется в любом случае** — включая промах; скрывать промах запрещено.
4. **Триггеры отмены** публикуются, но не скорируются: они нужны, чтобы промах был объясним.
5. **Не рекомендация.** В каждом флеше — дисклеймер; направления активов не являются советом.

## Как читать цифры

- **p(соб.)** — вероятность события на горизонт: годовая вероятность монитора пересчитана по
  постоянной интенсивности `p(h) = 1 − (1 − p_year)^(h/365)`. Допущение: конфликты кластеризуются,
  поэтому на коротких горизонтах оценка скорее занижена.
- **80% интервал** — рабочая неопределённость в логитах (±1,2816·0,6, шире на длинном горизонте).
  Это не доверительный интервал частотной статистики.
- **p клим.** — доля непересекающихся окон такой же длины в 2024–2026 гг., где актив двигался в
  предсказанную сторону не меньше порога. Базовая частота без утверждения о причине.
- **p флеш** — та же климатология, сдвинутая на вес уверенности канала (high 0,10; medium 0,06;
  low 0,03). Допущение, не калибровка — поэтому обе вероятности публикуются рядом.
- **Брайер** = (p − y)², меньше лучше; **лог-оценка** больше лучше; сравнение с климатологией
  показывает, добавляет ли флеш что-то к простой базовой частоте.

## Скоринг и проверка

```bash
python -I core/flash.py --collect     # исходы активов по ценам (когда срок наступил)
python -I core/flash.py --score       # scores.json
python -I core/flash.py --status      # таблица флешей
python -I core/flash.py --due         # ближайшие сроки → data/flash/due.json
```

Событие вносится в `data/flash/observations.json` вручную: `event` = 1/0, `checked` = дата,
`source` = выпуск UCDP Candidate или публичное сообщение. Если данных нет — `event` остаётся пустым,
флеш остаётся `pending`, замена не подставляется.

## Автоматика

страницы → тесты → ветка и PR. Автослияние зелёных PR — `merge-updates.yml`.

## Где смотреть

- `prototype/flash.html` — публичный трек-рекорд (тёмный «брифинг-терминал»), ссылка в шапке сайта
  («Флеш») и в подвале.
- `prototype/flash/index.html` и `prototype/flash_en/index.html` — витрина продукта (RU/EN): оффер, пилот, образцы.
- `prototype/flash/pilot.html` / `_en` — условия пилота; `weekly.html` — образец недельного обзора.
- `prototype/flash/docs.html` — документы: двуязычные описания и ссылки на файлы (`prototype/docs/md/`).
- `prototype/flash/refs.html` — литература: 95 источников, 8 групп, поиск по тексту.
- `prototype/flash/samples/Ф-0NN.html` и `prototype/flash_en/samples/Ф-0NN.html` — записки RU/EN.
- Переключатели на каждой странице: светлая/тёмная тема (`localStorage ivm-flash-theme`) и RU/EN
  (`data-href-ru` / `data-href-en` на `<body>`); выбор темы запоминается.
- API: `prototype/api/v1/flash/index.json`.

## Ограничения

- Рыночные ряды — Yahoo Finance, дневные закрытия; при недоступности ряда сохраняются прежние данные.
- Цены третьих сторон **не** выгружаются публично: в открытый трек-рекорд идут только наши
  вероятности и итоги скоринга.
- Первые 10 флешей зафиксированы 14.11.2026 с горизонтом 90 суток; первый скоринг — 12.02.2027.
  До этого трек-рекорд пуст по определению, и продавать продукт как проверенный нельзя.
- Вероятности монитора на 2026 г. предварительны (метки 2026 г. неполны) — флеш наследует оговорку.
